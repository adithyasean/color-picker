# Color Picker

A modern, native iOS memory matching game built with SwiftUI.

## 🎮 Features

### Game Modes
- **Classic (3×3)**: Perfect for beginners - no time limit
- **Medium (5×5)**: 12 pairs in 2 minutes - stepping up the challenge
- **Hard (7×7)**: 24 pairs in 3 minutes - for the brave
- **Progressive**: Start easy and progress through increasingly difficult levels

### Scoring System
- **Combo Multiplier**: Chain matches for up to 3x points
- **Streak Bonuses**: +15/30/50 for 3/5/7 consecutive matches
- **Time Bonuses**: Quick match, speed run, and clutch bonuses
- **Perfect Game**: +100 bonus for no mistakes

### 30+ Achievements
- Beginner, Mastery, Speed, Streak, Collection, and Secret categories
- Progress tracking with visual indicators
- Unlock celebrations with haptic feedback

### Premium UX
- Haptic feedback for all interactions
- 3D card flip animations
- Glassmorphic design
- Real-time bonus/penalty feedback
- Timer with color-coded progress bar

## 🚀 Getting Started

1. Open `ColorPicker.xcodeproj` in **Xcode 15+**
2. Select an iOS Simulator (e.g., iPhone 15)
3. Press **Run** (⌘ + R)
